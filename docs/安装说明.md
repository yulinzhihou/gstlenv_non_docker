# 安装说明

> 适用于：RHEL 系（CentOS 5~10、云厂商系统）与 Debian 系（Ubuntu 12~26、Debian 10~18）
> 安装方式：**非 Docker 原生安装**

---

## 一、系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | 见 README「支持系统矩阵」 |
| 架构 | x86_64（64 位系统，需支持 32 位兼容库） |
| 内存 | ≥ 2GB（推荐 4GB+，可 `tl_swap` 加虚拟内存） |
| 磁盘 | ≥ 10GB 空闲 |
| 权限 | root 用户 |
| 网络 | 能访问国内镜像源（阿里云/腾讯/华为/163/搜狐/清华）；完全离线环境需预置 offline/ 全量组件 |

> 纯 32 位系统 / 无法安装 32 位兼容库的系统：请改用 Docker 方案（gstlenv 离线镜像）。

---

## 二、安装前准备

1. **上传包**：将整个 `src` 目录上传至服务器任意位置（推荐 `/root/src`），保持目录结构完整。
2. **确认磁盘**：`df -h` 检查空间。
3. **放行端口**（安装后配置）：`3306（数据库）/ 13580（登录）/ 15680（游戏）/ 21818（billing）/ 51888、61888（web）`。
4. **（可选）指定数据库密码**：`TLBB_DB_PASS` 环境变量；默认 `123456`（对齐 gstlenv env.sample）。
5. **（可选）指定 MySQL 档位**：`TLBB_MYSQL_VERSION=51|57|80`；默认按系统自动选择（见下）。

---

## 三、安装步骤

### 3.1 一键安装

```bash
cd /root/src
bash install.sh
```

安装器自动完成：
1. 识别发行版与版本 → 映射安装家族（el5~el10 / ubuntu / debian）
2. 选择 MySQL 档位（对齐 gstlenv 编号：1=MySQL5.1 2=MySQL5.7 3=MySQL8.0，默认按系统自动）
3. 配置国内安装源（EOL 系统自动切换 vault / old-releases / archive 归档源）
4. 安装 32 位兼容库（glibc.i686 / libstdc++.i686 / libnsl.i686 / libcrypt.i686）
5. 安装数据库（**MySQL 5.1/5.7/8.0，不用 MariaDB**）：
   - el5/el6：yum mysql-server（vault 归档）
   - el7：离线 MySQL 5.1.73（内置 MySQL.tar.gz）
   - el8：MySQL 5.7（阿里云/华为云官方源，可切 8.0）
   - el9/el10：MySQL 8.0（官方源）
   - Ubuntu 12~16：系统源 MySQL 5.5/5.6
   - Ubuntu 18：系统源 MySQL 5.7
   - Ubuntu 20+：系统源 MySQL 8.0（真 MySQL，非 MariaDB）
   - Debian 10+：MySQL 官方 apt 源 8.0（阿里云镜像，避开 MariaDB 元包）
6. 启动数据库并等待就绪（MySQL 5.7/8.0 首启临时密码自动处理）
7. 创建 tlbbdb / web 库并导入 schema（root/gs 账号，默认密码 123456）
8. 安装 unixODBC + MySQL ODBC 驱动（32 位 libmyodbc3 必装；el7+ 追加 64 位 libmyodbc5）
9. 生成 /etc/odbc.ini / odbcinst.ini
10. 生成运行环境文件 /root/.tlbb/tlbb.env（默认值对齐 gstlenv env.sample）
11. 部署 tl_* 全局管理命令到 /usr/local/bin

### 3.2 免交互安装

```bash
TLBB_DB_PASS=你的密码 bash install.sh
```

### 3.3 指定离线组件目录（可选）

```bash
bash install.sh --offline-dir /自定义/offline
```

## 四、安装验证

安装完成后可执行：

```bash
# 1. 数据库运行状态
mysqladmin ping                     # 期望: mysqld is alive

# 2. 库已创建
mysql -uroot -p你的密码 -e "SHOW DATABASES;"   # 期望含 tlbbdb、web

# 3. ODBC 驱动就位
ls -l /usr/lib/libmyodbc3.so        # 32 位驱动
ls -l /usr/lib64/libmyodbc.so       # 64 位驱动 (el7+)

# 4. isql 连接测试
isql tlbbdb                          # 期望: Connected!

# 5. 管理命令可用
tl                                 # 期望: 显示命令菜单
```

## 五、验证失败排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 数据库未运行 | 源失效/包冲突 | `tl_curgs` 查看；重跑 `bash install.sh` |
| 32 位库安装失败 | EOL 源缺失 | 确认国内源已生效（`yum repolist`/`apt update`） |
| isql 连接失败 | 密码不符/驱动缺失 | 检查 /etc/odbc.ini 与密码；`tl_curgs` |
| 命令不存在 | 未部署成功 | 重跑 `bash install.sh` 或手动 `cp cmd/*.sh /usr/local/bin/tl_*` |
