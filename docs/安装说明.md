# 安装说明

> 适用于：RHEL 系（CentOS 5~10、云厂商系统）与 Debian 系（Ubuntu 12~26、Debian 10~18）
> 安装方式：**非 Docker 原生安装**

---

## 一、系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | 见 README「支持系统矩阵」 |
| 架构 | x86_64（64 位系统，需支持 32 位兼容库） |
| 内存 | ≥ 2GB（推荐 4GB+，可 `tl_swap` 加虚拟内存） |
| 磁盘 | ≥ 10GB 空闲 |
| 权限 | root 用户 |
| 网络 | 能访问国内镜像源（阿里云/腾讯/华为/163/搜狐/清华）；完全离线环境需预置 offline/ 全量组件 |

> 纯 32 位系统 / 无法安装 32 位兼容库的系统：请改用 Docker 方案（gstlenv 离线镜像）。

---

## 二、安装前准备

1. **上传包**：将整个 `src` 目录上传至服务器任意位置（推荐 `/root/src`），保持目录结构完整。
2. **确认磁盘**：`df -h` 检查空间。
3. **放行端口**（安装后配置）：`3306 / 7777 / 7778 / 9470 / 222`。
4. **（可选）指定数据库密码**：`TLBB_DB_PASS` 环境变量，要求 8 位以上。

---

## 三、安装步骤

### 3.1 一键安装

```bash
cd /root/src
bash install.sh
```

安装器自动完成：
1. 识别发行版与版本 → 映射安装家族（el5~el10 / ubuntu / debian）
2. 配置国内安装源（EOL 系统自动切换 vault / old-releases / archive 归档源）
3. 安装 32 位兼容库（glibc.i686 / libstdc++.i686 / libnsl.i686 / libcrypt.i686）
4. 安装数据库（el5/6/7 用离线 MySQL 5.1 rpm；el8+ 用国内源 MariaDB；deb 用 apt MariaDB）
5. 启动数据库并等待就绪
6. 创建 tlbbdb / web 库并导入 schema
7. 安装 unixODBC + MySQL ODBC 驱动（32 位 libmyodbc3 必装；el7+ 追加 64 位 libmyodbc5）
8. 生成 /etc/odbc.ini / odbcinst.ini
9. 生成运行环境文件 /root/.tlbb/tlbb.env
10. 部署 tl_* 全局管理命令到 /usr/local/bin

### 3.2 免交互安装

```bash
TLBB_DB_PASS=你的密码 bash install.sh
```

### 3.3 指定离线组件目录（可选）

```bash
bash install.sh --offline-dir /自定义/offline
```

---

## 四、安装验证

安装完成后可执行：

```bash
# 1. 数据库运行状态
mysqladmin ping                     # 期望: mysqld is alive

# 2. 库已创建
mysql -uroot -p你的密码 -e "SHOW DATABASES;"   # 期望含 tlbbdb、web

# 3. ODBC 驱动就位
ls -l /usr/lib/libmyodbc3.so        # 32 位驱动
ls -l /usr/lib64/libmyodbc.so       # 64 位驱动 (el7+)

# 4. isql 连接测试
isql tlbbdb                          # 期望: Connected!

# 5. 管理命令可用
tl                                 # 期望: 显示命令菜单
```

---

## 五、验证失败排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 数据库未运行 | 源失效/包冲突 | `tl_curgs` 查看；重跑 `bash install.sh` |
| 32 位库安装失败 | EOL 源缺失 | 确认国内源已生效（`yum repolist`/`apt update`） |
| isql 连接失败 | 密码不符/驱动缺失 | 检查 /etc/odbc.ini 与密码；`tl_curgs` |
| 命令不存在 | 未部署成功 | 重跑 `bash install.sh` 或手动 `cp cmd/*.sh /usr/local/bin/tl_*` |
