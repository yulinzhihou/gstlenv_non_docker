# 注意事项

## 一、端口与防火墙（默认值对齐 gstlenv env.sample）

| 端口 | 用途 |
|---|---|
| 3306 | MySQL（游戏服务端连接数据库，gstlenv 对外映射 33061，本机用 3306） |
| 13580 | 登录网关（gstlenv LOGIN_PORT） |
| 15680 | 游戏网关（gstlenv SERVER_PORT） |
| 21818 | billing 验证（gstlenv BILLING_PORT） |
| 51888 / 61888 | web 访问 / web GM（gstlenv WEB_PORT / WEB_GM_PORT） |

**云服务器**：需在控制台安全组放行以上端口；**本机**：`firewall-cmd` / `ufw` / `iptables` 放行。
> 安装器会自动关闭 selinux（若开启），避免 32 位进程加载驱动被拦截。

## 二、安全提醒

1. **数据库密码**：默认 `123456`（对齐 gstlenv），公网环境请安装时修改为强密码（`TLBB_DB_PASS=新密码 bash install.sh` 或 `tl_setconfig` 改）。
2. **tl_reset 会清空所有玩家数据**：执行前务必 `tl_backup`。
3. **tl_remove 只停止服务与移除命令**，数据保留；彻底删除需手动执行文档中说明的命令。
4. **公网开服风险**：请勿将 root 密码、数据库密码明文写在客户端配置中；建议用专用账号连接数据库（安装器已建 `gs` 账号，密码与 root 同默认 123456）。

## 三、系统兼容注意事项

### RHEL 系
- **CentOS 5**：已 EOL，仅支持 64 位；使用阿里云 centos-vault 5.11 归档源（http）。若 vault 源失效，离线 rpm 兜底（offline/el5/）可保证 unixODBC + 驱动安装。
- **CentOS 6/7/8**：已 EOL，自动切换 vault 归档源；若源失效请先 `yum clean all` 再重试。
- **数据库（不用 MariaDB）**：
  - el5/el6：MySQL 5.1（yum vault 归档）
  - el7：MySQL 5.1.73（内置离线包 MySQL.tar.gz，无网络可用）；如需 5.7 指定 `TLBB_MYSQL_VERSION=57`
  - el8：MySQL 5.7（默认，官方源阿里云/华为云镜像；可切 8.0）
  - el9/el10：MySQL 8.0（官方源；64 位源端引擎需自行替换 SQL 和 ini，对齐 gstlenv 编号4）
- **MySQL 5.7/8.0 官方源**：自动探测阿里云 `mirrors.aliyun.com/mysql` → 华为云 `repo.huaweicloud.com/mysql` → 腾讯云，均不可达时回退 `repo.mysql.com`；源文件 `/etc/yum.repos.d/mysql-community.repo`（gpgcheck=0 便于内网/离线）。
- **32 位兼容库**：与内核/glibc 版本强绑定，无法通用离线，必须走系统源。若系统源失效需先修复源（本包已自动处理 EOL 归档）。

### Debian 系
- **Ubuntu 12~17 / Debian 10**：EOL，走 old-releases / archive.debian.org 归档源，偶发不稳定，若失败建议改用 Docker 方案。
- **数据库（不用 MariaDB）**：
  - Ubuntu 12~16：系统源 MySQL 5.5/5.6
  - Ubuntu 18：系统源 MySQL 5.7
  - Ubuntu 20+：系统源 MySQL 8.0（Ubuntu 官方 mysql-server 即真 MySQL，非 MariaDB）
  - Debian 10+：**MySQL 官方 apt 源 8.0**（阿里云镜像 `mirrors.aliyun.com/mysql/apt/debian/`，Debian 的 mysql-server 元包是 MariaDB 别名，必须走官方源）
- **i386 多架构**：安装器会自动 `dpkg --add-architecture i386`，需要网络下载 i386 索引。
- **Debian 14~18**：截至当前未正式发布，安装器自动回退最新稳定版代号。

## 四、服务端注意事项

1. **服务端压缩包必须上传到 /root**，且命名为 `tlbb.tar.gz` 或 `tlbb.zip`（tl_untar 固定从此读取）。
2. **32 位进程**：服务端二进制为 32 位，ODBC 驱动必须用 32 位 libmyodbc3（安装器已配置 /etc/odbc.ini 指向 32 位驱动）。
3. **换端**：`tl_change` 会自动备份旧端（/home/tlbb/tlbb.bak.*），确认新端正常后再删除备份。
4. **删档**：`tl_reset` 支持选择「内置初始数据」或「备份数据」两种还原方式。
5. **数据库结构差异**：不同服务端版本的账号/点数表结构可能不同（t_account / account 等），`tl_setvalid` / `tl_setpoint` 若未生效，请以 tlbbdb.sql 中实际表结构为准。
6. **MySQL 8.0 注意事项**：安装器已强制 `mysql_native_password` 认证并卸载 validate_password 组件（兼容 ODBC 3.51 / 老驱动）；8.0 需使用 64 位源端引擎，若为 32 位怀旧端请选 MySQL 5.1/5.7 档位。

## 五、常见问题（FAQ）

**Q1: 安装时提示「32 位兼容库安装不完整」？**
A: EOL 系统的 i686 包可能缺失，属正常现象。重点确认 glibc.i686 与 libstdc++.i686 已装（ODBC 驱动依赖），其余缺失不影响开服。

**Q2: isql 连接提示找不到驱动？**
A: 确认 `/usr/lib/libmyodbc3.so` 存在；检查 /etc/odbc.ini 中 Driver 路径与 /etc/odbcinst.ini 注册项。

**Q3: 服务端启动后端口未监听？**
A: 查看 `tl_gslog -f` 日志；确认 ServerInfo.ini 中数据库 IP/密码与安装时一致（可 `tl_setini` 重写）。

**Q4: 如何在完全离线的服务器安装？**
A: 将整个 src 目录（含 offline/ 全部组件）上传后执行 `bash install.sh`；离线时若 yum/apt 源不可用，安装器会跳过源配置，el5/6/7 的数据库与驱动由离线组件完成，el8+/deb 的数据库需在联网机器上离线下载 deb/rpm 后放入 offline 相应目录（`offline/rpm-packages/<elX>/mysql57|mysql80/`、`offline/deb-packages/mysql80/`）。

**Q5: 与 Docker 版 gstlenv 有什么区别？**
A: 本包为原生安装（直接装到系统，性能最好、无容器开销）；gstlenv 为容器化（隔离、不污染系统、适合 Windows/WSL 导入离线镜像）。两者数据文件（tlbbdb.sql / 驱动）同源，可互换使用。命令体系完全对齐：`gs` 原名 + `tl_` 兼容名，默认端口/密码一致（Login 13580 / Server 15680 / Billing 21818 / DB 密码 123456）。
