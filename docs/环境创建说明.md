# 环境创建说明（从零到开服）

> 目标：在一台全新的 Linux 服务器上，从安装环境到跑起《天龙八部》服务端。

---

## 阶段一：安装运行环境（约 5~15 分钟）

```bash
# 1. 上传 src 目录到服务器
#    例: scp -r src root@服务器IP:/root/

# 2. 进入并安装
cd /root/src
bash install.sh
```

安装完成标志：看到「TLBB 原生环境安装完成」横幅，且 `tl` 命令可用。

---

## 阶段二：准备服务端文件

### 2.1 获取服务端压缩包

- 格式：`tlbb.tar.gz` 或 `tlbb.zip`
- 上传位置：**/root 目录**（必须是 /root，untar 命令固定从此处读取）

```bash
# 例: 上传后确认
ls -l /root/tlbb.tar.gz
```

### 2.2 解压服务端

```bash
tl_untar
# 期望: [OK] tlbb.tar.gz 解压完成 -> /home/tlbb
```

---

## 阶段三：配置服务端

### 3.1 写入数据库配置

```bash
tl_setini
```

自动将数据库 IP/端口/账号/密码写入服务端 `config/ServerInfo.ini`。

### 3.2 检查配置（可选）

```bash
cat /home/tlbb/tlbb/config/ServerInfo.ini   # 路径按实际解压结果
tl_curgs                                     # 查看环境总配置
```

---

## 阶段四：启动开服

```bash
# 1. 开启服务端
tl_runtlbb

# 2. 查看状态（进程 + 端口）
tl_runtop

# 3. 查看日志（确认无报错）
tl_gslog -f
```

**开服成功标志**：`runtop` 显示 7777/7778/9470 端口均在监听，日志无致命错误。

---

## 阶段五：客户端连接

1. 修改客户端 `ServerList.txt` 服务器 IP 为本机公网 IP；
2. 安全组 / 防火墙放行：`3306 / 7777 / 7778 / 9470 / 222`；
3. 客户端登录测试。

---

## 日常运维速查

| 操作 | 命令 |
|---|---|
| 关服 | `tl_close` |
| 重启 | `tl_restart` |
| 备份数据库 | `tl_backup`（存 /root/backup/） |
| 还原数据库 | `tl_restore [备份文件]` |
| 删档重导 | `tl_reset`（会清空玩家数据！先备份） |
| 封号 / 解封 | `tl_setvalid 账号 1` / `tl_setvalid 账号 0` |
| 充值点数 | `tl_setpoint 账号 5000` |
| 增加虚拟内存 | `tl_swap 4`（4GB） |
| 换端 | 上传新包到 /root 后 `tl_change` |
| 清理日志 | `tl_rmlog` |
| 备份日志 | `tl_logbak` |
| 删除旧备份 | `tl_delbak 5`（保留 5 份） |
| 重构环境 | `tl_rebuild` |
| 卸载 | `tl_remove` |
