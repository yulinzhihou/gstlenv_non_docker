# 环境创建说明（从零到开服）

> 目标：在一台全新的 Linux 服务器上，从安装环境到跑起《天龙八部》服务端。
> 命令体系与 gstlenv 完全一致（gs 原命令名），帮助入口：`gs`，统一入口：`gsctl <命令> [参数...]`。

---

## 阶段一：安装运行环境（约 5~15 分钟）

```bash
# 1. 上传 src 目录到服务器
#    例: scp -r src root@服务器IP:/root/

# 2. 进入并安装
cd /root/src
bash install.sh
```

安装完成标志：看到「TLBB 原生环境安装完成」横幅，且 `gs` 命令可用。

---

## 阶段二：准备服务端文件

### 2.1 获取服务端压缩包

- 格式：`tlbb.tar.gz` 或 `tlbb.zip`
- 上传位置：**/root 目录**（必须是 /root，untar 命令固定从此处读取）

```bash
# 例: 上传后确认
ls -l /root/tlbb.tar.gz
```

### 2.2 解压服务端

```bash
untar
# 期望: 服务端文件【tlbb.tar.gz】已经解压成功！ -> /tlgame/tlbb
# 旧端自动备份为 /root/tlgame-时间戳.tar.gz
```

---

## 阶段三：配置服务端

### 3.1 写入数据库配置

```bash
setini
```

自动将数据库 IP/端口/账号/密码写入服务端 `config/ServerInfo.ini`、`LoginInfo.ini`、`ShareMemInfo.ini`，
并生成 /etc/odbc.ini 与 billing 的 /home/billing/config.yaml。

### 3.2 检查配置（可选）

```bash
cat /tlgame/tlbb/Server/Config/ServerInfo.ini   # 服务端实际配置文件
curgs                                            # 查看环境总配置
```

---

## 阶段四：启动开服

```bash
# 1. 开启服务端
runtlbb

# 2. 查看状态（进程 + 端口）
runtop

# 3. 查看日志（确认无报错）
gslog
```

**开服成功标志**：`runtop` 显示数据库(3306)/登录(13580)/游戏(15680)/billing(21818) 端口均在监听，日志无致命错误。

---

## 阶段五：客户端连接

1. 修改客户端 `ServerList.txt` 服务器 IP 为本机公网 IP；
2. 安全组 / 防火墙放行：`3306 / 13580 / 15680 / 21818 / 51888 / 61888`（默认值对齐 gstlenv）；
3. 客户端登录测试。

---

## 日常运维速查

| 操作 | 命令 |
|---|---|
| 命令帮助 | `gs`（菜单）/ `gsctl <命令> [参数...]`（统一入口） |
| 关服 | `close` |
| 重启 | `restart` |
| 备份数据库+版本 | `backup`（0=全部 1=版本 2=数据库，存 /tlgame/backup/） |
| 还原数据库 | `restore web 备份文件绝对路径` / `restore tlbbdb 备份文件绝对路径` |
| 删档重导 | `reset`（会清空玩家数据！先 backup） |
| 封号 / 解封 | `setvalid 账号 1` / `setvalid 账号` |
| 充值点数 | `setpoint point 5000 账号`（类型: point/yuanbao/zengdian/menpaipoint/guildpoint/points/vmoney） |
| 增加虚拟内存 | `swap 4`（4GB） |
| 换端 | 上传新包到 /root 后 `change` |
| 清理日志 | `rmlog` |
| 备份日志 | `logbak`（`logbak cron 1 10` 定时） |
| 删除旧备份 | `delbak 5`（保留 5 份） |
| 重构环境 | `rebuild` |
| 卸载 | `remove` |
