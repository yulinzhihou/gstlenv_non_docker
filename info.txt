
==============================================================
       GS游享网 · 天龙八部 万能环境 (非 Docker 原生版)
==============================================================
  官网: https://gsgameshare.com
  项目: https://github.com/yulinzhihou/gstlenv_non_docker
--------------------------------------------------------------
  支持系统:
    RHEL 系: CentOS 5/6/7/8/9/10, Rocky/Alma 8/9, Oracle Linux
            阿里云 Alinux 2/3/4, Anolis 8/23
            腾讯云 TencentOS 2/3/4
            华为 openEuler 20~25, EulerOS 2.x
    Debian 系: Ubuntu 12~26, Debian 10~18
--------------------------------------------------------------
  功能特性:
    1. 一条命令在线安装 (curl | bash)
    2. 离线安装模式 (无网络, 本地 rpm/deb 命令安装)
    3. 国内安装源 (阿里云/腾讯/华为/163/搜狐/清华, EOL 自动归档)
    4. MySQL 5.1 / 5.7 / 8.0 多档位 (不用 MariaDB)
    5. unixODBC + MySQL ODBC 驱动 (32 位 + 64 位)
    6. 命令体系与 gstlenv 完全一致 (gs 原命令名)
    7. 集成分步调试开服/日志/备份/封号/充值等全套运维命令
--------------------------------------------------------------
  本环境仅供学习研究使用, 请在 24 小时内删除, 勿用于商业用途
  如有问题, 请访问 GS游享网 (gsgameshare.com)
